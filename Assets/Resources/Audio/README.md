# 🎧 音の置き場

`SoundSystem` は **まずここを探し、無ければ手続き生成に落とす**。
だから 1 本置くごとに、その音だけが本物に差し替わる（全部揃うまで待たなくてよい）。

| フォルダ | 中身 | 何が id か |
|---|---|---|
| `Sfx/`   | 効果音 | `AudioAssets.SfxAt(i).id`（`SoundSystem.Sfx` と同じ並び） |
| `Bgm/`   | 曲（ループ前提） | `prepare` / `battle` / `surface` |
| `Voice/` | 決まった場面の一言 | `v_*` |

## 決まりごと
- ファイル名は **id そのまま**（`click.mp3` など）。`Resources.Load` は拡張子を見ないので mp3/wav どちらでもよい。
- ⚠ **`Assets/Resources/` の外に置くとビルドに入らない**（実行時に読めない）。
- BGM は Unity のインポート設定で **Loop** を意識すること（曲側で継ぎ目を作らない）。
- 声は**動く文章を喋らせない**。進言の本文はターンごとに変わるので、
  読み上げると生成が終わらない。何度も来る決まった場面だけを置く。

目録の本体（いつ鳴るか・生成の指示）は `Assets/Scripts/AudioAssets.cs`。
