## 結論：壁は動かなかった（T13/T14 → T14）

### W-1/W-2 は**設計どおり効いた**
- 巣と環境が**初めて置かれた**（T2・進言 94/90 が効いた）。
- 大招集が**1度も出なかった**。守りが薄い（12/14枠・巣1・配下2）ため readiness が Risky で、
  進言の重みが 90→62 に落ちて**上位3件から押し出された**。＝ W-2 は無謀な賭けを止めた。

### ⚠⚠ だが同じターンで死んだ ―― **止めた手は経済の本体でもあった**
大招集は撃破・DP・RP・**時代の進行**の主エンジンだった。切らなくなった結果：
時代は **Dawn のまま**／RP 65／撃破 71（2周目の 40%）。
一方、逃走 55 が積み上がって**世界の装備水準が 57.3**まで走り、配下2体では捌けなくなった。
＝ **無謀な死（2周目）を、貧しい死（3周目）に置き換えただけ。**

### ⚠⚠⚠ 3周に共通する本体：**T4 以降、盤が一度も大きくならない**
| | 3周とも |
|---|---|
| 階層 | **1 のまま**（追加も拡張も0回） |
| 配置枠 | **T4 で 12/14 に達したあと不動** |
| 配下の数 | 3周とも **2〜6 体**。波は 4人 → 19人 |

原因は進言の側にある：
- **拡張・階層追加の進言が存在しない**（全34件の見出しに1つも無い）。
- **「配下を召喚して数を増やす」は weight 55 ＝ 全進言中の最下位**。しかも進言は
  **上位3件しか出ない**（`Build` が3件で打ち切り）。競合は 76〜99 なので、
  **14ターン通して一度も画面に出なかった**（実測：出現0回）。
- ＝ 「呼ぶ人数は青天井、捌く頭数は誰も勧めない」という2周目の診断が、**そのまま残っている**。
  W-1/W-2 は**選ぶ材料**を足したが、**選択肢そのもの**は足していない。

### ⚠ W-2 の指標そのものの弱点
`BestWaveHeld`（一人も通さず凌いだ最大）は **T4 の 7 から最後まで動かなかった**。
逃走が常態になると条件が二度と満たされず、readiness が**永久に Risky に貼り付く**。
＝ 一度荒れると「もう大招集はするな」と言い続ける片道の指標になっている。
