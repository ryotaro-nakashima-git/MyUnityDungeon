## 3. 新しく分かったこと：死に方は2つ、最後はどちらも「殻22%」を通る

戦闘中の手（号令・感情の刈り取り・誘引／過負荷）の有無で比べた。**判断は4倍**（下の⚠を参照）。

| 4倍・各10周 | 生存の中央値 | 死んだターン | 逃走率 T16〜20 | 1波の人数 T16〜20 |
|---|---|---|---|---|
| 手あり（`eq4b`） | T24（T23〜28） | **T23〜30 にそろう** | 0.53 | 24.6 |
| 手なし（`noact4`） | T19（T12〜46） | **二極**：6周が T12〜19、残りは T29〜52 | 0.10 | 21.8 |

ログランク p = 0.311（中央値の差は言えない）。**違うのは分布の形**。

- **手ありの死に方＝逃走 → 脅威度 → 大きな波の悪循環（長期）**。逃がすほど脅威度が上がり、次の波が大きく強くなり、さらに逃がす
  （正の帰還＝止まらない増幅）。号令『恐慌の波』（冒険者を逃げ帰らせる）が逃走の約半分を作る（16倍での切り分け：逃走率 0.43 → 恐慌なし 0.21 → 手なし 0.09）。
- **手なしの死に方＝魔王まで届いて削られる（短期）**。冒険者はほぼ全員倒している（逃走 0〜5人）のに、魔王のHPが 1.0 → 0.70 → 0.22 と削られる。
  治癒・落石・魔王の一撃が無いと、早い段階の強い波を受け止めきれない。
- ⭐ **どちらも最後は殻 22% に貼り付いて討たれる**（§2.3 の吸い込み状態）。→ 系4 がいちばん効く手当て。
- 手の効き目は**トレードオフ**：手は短期の危機を救うが、逃がすことで長期の悪循環を回す。
  ⚠ 自動運転は恐慌を「使えるたびに」押す。人の使い方とは違う可能性が高いが、
  「押すと長期的に損をする手が短期的には得に見える」こと自体は、帰還の利得が高すぎるという設計上の問題。

⚠⚠ **16倍は群どうしの比較まで歪めていた**：16倍では 手あり T31 ／ 手なし T43（p=0.005）で「手を使うほど早く死ぬ」ように見えたが、
16倍は守り有利にずれていて、手なしが早い危機で死ぬ周がほとんど出なかった（`noact16`）。
⇒ **速さのずれは群ごとに違う向きで効く**。16倍は「ふるい分け」にも使わず、**P1 以降の判断はすべて4倍**で行う（仕様 §9.4 を改訂）。

## 4. P2 への入力

1. **系1**：通り道が満席（8マス・8体）で、処理能力が頭打ち。人数の決め方を目標の負荷率から導く前に、
   **通り道の幅と階層を設計の量として扱う**（階層を増やす道が実際に使われていない）。
2. ⭐ **系4（最優先）**：殻 20%台の吸い込みを解消する（脱出確率が 0 でない形へ）。**2つの死に方の両方がここを通る**。
3. **帰還の利得**：逃走 → 脅威度の上がり方（`LureEconomy`）が強すぎる。脅威度に飽和か減衰を入れるか、
   逃がす手に見合う見返りと上限を決める。⚠ 変えるなら「泳がせ」（わざと逃がす遊び）を殺さないこと。
4. **基準プレイヤー**：自動運転の手の方針を決め直す（恐慌を使えるたびに押すのは基準として不適切）。

## 5. 残っている計測の穴
- 4倍と16倍の残るずれの原因（接触判定・射程の出入り・1フレーム1回までの攻撃が候補）。
- 4倍の標準の手の周を 20 周に増やす（いま 10 周）。
