## ⚠⚠ 一番大事な発見：**40,210 DP を持ったまま、枠を半分空けて負けた**
負けた原因は「お金が足りない」ではない。**お金が防衛力に変わらなかった**。
- 罠は150DPなので、空いていた24枠を全部埋めても **3,600DP**。所持の 1/11 で足りた
- なのに私は各階5個で止めた ＝ **プレイの誤り**。ただし…
- **ゲームは一度も「枠が空いている」と言わなかった。** 進言にその項目はあるのに、
  進化・遺物・感情ツリーに weight で負けて3枠に一度も入らなかった（T8の進言＝進化/遺物/感情）

→ **進言の優先度が、いま本当に効く手を指していない。**
   「DPが余っていて配置枠が空いている」は、序盤の遺物や感情より**ずっと差し迫った手**。

# 2周目：T4で敗北（私の手順ミス）＋ そこで見つかった実バグ2件

## 実バグ①：**新しい周を始めてもターン番号とフェーズが戻らない**（修正済み）
`currentTurn` はフィールドの初期値 1 で始まるだけで、**周をまたいでリセットする場所が無かった**。
実測：T13で敗北 → もう一度始めると **T13の防衛戦のまま**始まる（名簿の人数もレベルもT13の値）。
→ `DungeonTurnManager.ResetRun()` を足し、`StartNewGame` から呼ぶようにした。

## 実バグ②候補：**拡張は配置を全部消すのに、突入前に止めてくれない**
2周目は「拡張 → 配置が全消し → そのまま侵略開始」で**無防備のまま突入し、T4で魔王が死んだ**。
これは私の手順ミスだが、**プレイヤーも同じ順序で同じ事故を起こせる**。
進言には「まず罠を1つ置く」(weight 99) があるが、**報告を開かなければ見えない**。
→ 提案：`侵略開始` を押したとき、**この階に何も置いていなければ確認を出す**。

## T11 の内訳＝**私が使わなかった力**
```
DP 17,120 ／ 素材 281 ／ 魔王BP 76 ／ 感情ツリー 0個 ／ 召喚できる種 7（進化ゼロ）
```

## 結論：**量（枠）を埋めても足りない。壁は「質」にある**
- 枠を全部埋めた（30/30×2階）のに、T10・T11 は**撃破0**
- 私の配下は **Lv14の素のスケルトン**。装備を鍛えず、進化させず、感情ツリーもBPも触っていない
- ＝ **数の軸は飽和し、質の軸（進化・鍛造・感情・魔王BP）に投資しないと T10 前後で壁**

そして**ゲームはそれを教えない**：
進言は「遺物を装備する」「感情ツリーを開く」を出すが、
**「素材281が眠っている」「BPが76眠っている」「装備を鍛えると+22%」を、壁の手前で強く指さない**。
